# 🛡️ 坦克大战（HTML5）

一款纯 HTML5 Canvas + 原生 JavaScript 实现的坦克大战小游戏，**零依赖、零图片素材**，所有画面由 Canvas 绘制，音效由 WebAudio 实时合成。

## ✨ 特色玩法

- 🖱️ **鼠标瞄准射击**：炮塔 360° 独立旋转，指哪打哪；敌人也会瞄准玩家斜射
- 🎱 **反弹弹道**：炮弹在墙壁与边界间反弹（最多 4 次）直到击中坦克，敌方炮弹会误伤友军
- 🎁 **地图道具**：定时刷新 + 击毁掉落，**敌我双方都能拾取**——爆破弹 / 穿透弹 / 冰冻弹 / 散弹炮 / 加速 / 护盾 / 生命 / ☢️核弹（全屏打击）
- 🌀 **传送门**：坦克和炮弹进入后从配对出口出现，攻守奇袭必备
- 💥 **爆炸桶**：击中引发连锁爆炸，不分敌我
- 👹 **每关都有 BOSS**：扇形弹幕、追踪玩家，血量逐关递增（6→14）
- 🎁 **Roguelike 强化**：每关通过后三选一 Buff，可叠加
- 🗺️ 5 个手工设计关卡，敌人数量与强度逐关提升

## 🚀 本地运行

无需任何构建工具，直接用浏览器打开 `index.html` 即可。

也可以启动一个本地服务器：

```bash
# Python
python -m http.server 8000

# Node.js
npx serve .
```

然后访问 `http://localhost:8000`。

## 📜 游戏规则

- 保护底部的**金色基地**（被击中则游戏失败），消灭本关所有敌方坦克即可过关，共 5 关。
- 🧱 砖墙可被击破；⬜ 钢墙无法摧毁；🌊 河流阻挡坦克；🌿 草丛可隐蔽；💥 爆炸桶被击中会连锁引爆，伤害不分敌我。
- 🌀 **传送门**成对出现，坦克和炮弹进入后从另一端出来。
- 🎁 **道具**会定时刷新在地图上，击毁敌人也会掉落；敌人拾取道具同样会获得强化（核弹除外——敌人捡了会自伤）。
- 敌方坦克：灰色普通(100) / 蓝色快速(200) / 红色重型 2 血(300) / 紫色精英 3 血(500) / **BOSS**(1000+，每关压轴，扇形弹幕)。
- 每关通过后从 3 个随机强化中选择 1 个，效果可叠加。
- 玩家初始 3 条生命，阵亡后短暂无敌重生。

## 🛠️ 技术要点

- Canvas 2D 渲染，16×16 瓦片地图，5 个手工设计关卡
- 基于 AABB 的碰撞检测；子弹为任意角度矢量运动，逐轴反射实现反弹物理
- 传送门配对传送（坦克与子弹均可），爆炸桶连锁引爆
- 道具系统：定时刷新 + 击杀掉落，敌我双方均可拾取
- 敌方 AI：巡逻 + 追踪 + 瞄准射击 + 连发；BOSS 扇形弹幕并主动追击
- 车身与炮塔分离渲染：车身随移动方向，炮塔随瞄准角度
- WebAudio API 合成全部音效，零音频文件
