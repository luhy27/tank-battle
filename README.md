# 🛡️ 坦克大战（HTML5）

一款纯 HTML5 Canvas + 原生 JavaScript 实现的经典坦克大战小游戏，**零依赖、零图片素材**，所有画面由 Canvas 绘制，音效由 WebAudio 实时合成。

## 🎮 在线试玩

开启 GitHub Pages 后即可在线游玩：

> `https://<你的用户名>.github.io/<仓库名>/`

## 🚀 本地运行

无需任何构建工具，直接用浏览器打开 `index.html` 即可。

也可以启动一个本地服务器：

```bash
# Python
python -m http.server 8000

# Node.js
npx serve .
```

然后访问 `http://localhost:8000`。

## 📜 游戏规则

- 保护底部的**金色基地**（被击中则游戏失败），消灭本关所有敌方坦克即可过关。
- 🧱 砖墙可被炮弹击破；⬜ 钢墙无法摧毁；🌊 河流阻挡坦克但子弹可飞过；🌿 草丛可隐蔽坦克。
- 敌方坦克有三种：
  - **灰色** 普通型：速度中等，1 发击毁（100 分）
  - **蓝色** 快速型：速度快，1 发击毁（200 分）
  - **红色** 重型：速度慢，需要 2 发击毁（300 分）
- 共 3 个关卡，难度递增。玩家初始 3 条生命，阵亡后短暂无敌重生。
- 炮弹可以击毁砖墙、抵消敌方炮弹。

## 🛠️ 技术要点

- Canvas 2D 渲染，16×16 瓦片地图，三个手工设计关卡
- 基于 AABB 的碰撞检测（坦克-地形、坦克-坦克、子弹-地形、子弹-坦克、子弹-子弹）
- 简单的敌方 AI：随机巡逻 + 朝玩家/基地方向推进 + 随机开火
- WebAudio API 合成射击、爆炸等音效，无需音频文件
