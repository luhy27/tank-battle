# 🛡️ 坦克大战（HTML5）

一款纯 HTML5 Canvas + 原生 JavaScript 实现的坦克大战小游戏，**零依赖、零图片素材**，所有画面由 Canvas 绘制，音效由 WebAudio 实时合成。

## ✨ 特色玩法

- 🎱 **反弹弹道**：所有炮弹都会在墙壁与边界间反弹（最多 4 次），直到击中坦克才消失——流弹无情，敌方炮弹也会误伤它们自己！
- 🎁 **Roguelike 强化**：每关通过后三选一 Buff：穿透弹、爆破弹、冰冻弹、高爆弹头、炮管扩容、极速射速、引擎强化、增援生命、基地加固
- 👾 **敌人逐关增强**：移速与射速逐关提升，高关卡敌人会瞄准玩家、双连发；紫色精英坦克 3 点血量
- 👹 **最终 BOSS**：第 5 关压轴登场，10 点血量、三向散射
- 🗺️ 5 个手工设计关卡，地形包含砖墙 / 钢墙 / 河流 / 草丛

## 🚀 本地运行

无需任何构建工具，直接用浏览器打开 `index.html` 即可。

也可以启动一个本地服务器：

```bash
# Python
python -m http.server 8000

# Node.js
npx serve .
```

然后访问 `http://localhost:8000`。

## 📜 游戏规则

- 保护底部的**金色基地**（被击中则游戏失败），消灭本关所有敌方坦克即可过关，共 5 关。
- 🧱 砖墙可被炮弹击破；⬜ 钢墙无法摧毁；🌊 河流阻挡坦克但子弹可飞过；🌿 草丛可隐蔽坦克。
- 炮弹击中墙壁会**反弹**，最多反弹 4 次后消失；敌我炮弹相撞会抵消。
- 敌方坦克：
  - **灰色** 普通型：100 分
  - **蓝色** 快速型：速度快，200 分
  - **红色** 重型：2 血，300 分
  - **紫色** 精英：3 血，500 分（第 3 关起登场）
  - **BOSS**：10 血、三向散射，1000 分（第 5 关压轴）
- 每关通过后从 3 个随机强化中选择 1 个，强化效果可叠加。
- 玩家初始 3 条生命，阵亡后短暂无敌重生。

## 🛠️ 技术要点

- Canvas 2D 渲染，16×16 瓦片地图，5 个手工设计关卡
- 基于 AABB 的碰撞检测（坦克-地形、坦克-坦克、子弹-地形、子弹-坦克、子弹-子弹）
- 子弹反弹物理：轴对齐反射 + 反弹次数与存活时间上限
- 敌方 AI：随机巡逻 + 朝玩家/基地推进 + 瞄准射击 + 连发 + BOSS 三向散射，强度随关卡递增
- Roguelike 强化系统：9 种可叠加 Buff，每关三选一
- WebAudio API 合成射击、爆炸等音效，无需音频文件
